Что за кейс: Java enterprise-приложение для электронного создания и сопровождения заявок патентной направленности. Используется для автоматизации обработки, согласования и сопровождения патентных заявок.

Feedback signals: L1+
Есть staging, nightly deployment из dev, интеграционные тесты и тестовые окружения. Unit tests устарели, часть проверок выполняется вручную.

Context substrate: L1-
Основной контекст доступен через кодовую базу, Jira и Confluence, но документация местами устарела и не всегда отражает актуальное состояние системы.

Blast radius control: L1
Изменения проходят через feature branches, PR review и staging перед production. Но все равно есть узкие места, которые можно не заметитить

Карта доступов (из презентации):

GitHub: Есть
CI/CD: Есть
Jira: Есть
Staging: Есть
Pre-commit / secrets: нет

Самое слабое место: отсутствие pre-commit hooks и secret scanning, что повышает риск утечки секретов и небезопасных изменений.
